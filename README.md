# CLOSET — 发布产物

这个仓库**只放安装包与自动更新清单，不放源码**。

## 第一次安装

下载 `CLOSET_<版本>_aarch64.dmg`，拖进「应用程序」。**第一次打开会被系统拦一次**，
因为这个应用没有经过 Apple 公证。放行一次就永久有效：

1. 双击 CLOSET，弹出「Apple 无法验证 "CLOSET" 是否含有恶意软件」——  点 **Done**
   （**别点 Move to Bin**）
2. 打开「系统设置 → 隐私与安全性」，往下滚到 **「安全性」** 那一段
3. 「已阻止使用 "CLOSET"」那一行，点右边的 **「仍要打开」**
4. 用 Touch ID 或密码验证
5. 再弹一次确认，点 **「仍要打开」**

之后双击就能直接开。**macOS 15 之前是「右键点图标选打开」，新系统上 Apple 取消了那条路**，
网上搜到的老教程会让你白折腾。

**第一次打开要等一两分钟**（应用在准备本机的图像处理），期间显示一张启动画面，不是卡住。
之后每次都是几秒。

## 文件说明

- `CLOSET_<版本>_aarch64.dmg` —— macOS（Apple 芯片）安装包
- `CLOSET.app.tar.gz` + `.sig` —— 应用内「检查更新」用的更新包与签名
- `latest.json` —— 更新清单。应用读的是
  `https://github.com/jx921170819-dev/closet-releases/releases/latest/download/latest.json`，
  所以**每一版都要重新上传这个文件**

源码在另一个私有仓库里。这个仓库之所以是公开的，是因为应用要匿名读取它的 release ——
把访问私有仓的 token 打进应用等于把源码读权限发给每一个用户。
